✨ What is NepaliLang?

NepaliLang (also known as NepaliCode) is a brand-new programming language designed right here in Nepal. It draws inspiration from Python, which is famous for being easy to learn and use, but it's special because it lets you write programs using Nepali words and phrases. That means you can create software, learn programming concepts, and build projects using the language you're most comfortable with.

If you've ever felt that programming is hard because it's all in English, NepaliLang removes that barrier completely. Whether you're a student, a professional, or just curious about coding, NepaliLang is here to help you understand programming in a natural, intuitive way — using Unicode support for Nepali script (Devanagari) and English alike.

🌈 Why You'll Love NepaliLang

🧠 Python-Inspired Syntax

If you've ever seen Python code, you know how clean and simple it looks. NepaliLang follows that same style, making it easy to read, write, and understand — but with Nepali keywords.

🔤 Full Unicode Support

Write variable names, strings, comments, and functions in Nepali Devanagari script or English — whatever feels natural to you. Your code speaks your language.

⚙️ High-Performance Bytecode VM

NepaliLang isn't just a toy in a browser. It runs on a powerful virtual machine that compiles your code into efficient bytecode, so your programs run fast and smoothly.

📚 Standard Library Included

You get a built-in library with pre-made tools for file handling, math operations, text processing, and more — so you can focus on building, not reinventing the wheel.

🖥️ Command-Line Magic

NepaliLang comes with a powerful CLI (Command-Line Interface) that makes running scripts, testing snippets, and exploring the language super easy — right from your terminal.

🔧 VS Code Extension

Get syntax highlighting, code completion, and debugging support directly inside Visual Studio Code (VS Code) — the most loved code editor in the world. Just install the extension and you're ready.

Once installed, open your Command Prompt (search for "cmd" in the Start menu) and type:

Press Enter. If you see something like NepaliLang version x.x.x, congratulations — you're all set!

💻 Your First Nepali Program

Let's write your very first "Hello, World!" program in Nepali. It's a tradition!

Open any text editor (like Notepad) and type the following:

नाम = "नमस्ते संसार"
छाप्नुहोस्(नाम)

Save the file as hello.np (the .np extension stands for Nepali Program!).

Now, in your Command Prompt, type:

nepali hello.np

And watch as your screen prints: नमस्ते संसार — "Hello World" in Nepali. Amazing, right?

🔮 What Makes NepaliLang Special

🌏 A True Local Language Language

NepaliLang isn't just an English programming language with Nepali labels. It's a full-fledged, intentional language that respects Nepali grammar, vocabulary, and culture. Every keyword, function name, and library tool has been thoughtfully designed for Nepali speakers.

🧰 Built-In Standard Library

No need to hunt for packages. NepaliLang ships with a rich standard library for common tasks — file I/O, math operations, string handling, date time, data structures, and more. All documented and easy to use.

⚡ Blazing Fast Execution

Powered by a custom bytecode virtual machine (VM), NepaliLang compiles source into compact bytecode, which the VM executes quickly. You get a smooth, responsive experience whether you're running simple scripts or bigger programs.

🛠️ VS Code Integration

NepaliLang provides a dedicated VS Code extension that brings syntax highlighting (color coding), autocomplete (suggestions as you type), and friendly error messages. The extension makes the coding experience modern and delightful.
